GovStack has several types of publications. This chapter sets out what kinds of document it publishes, what is the scope for each, and how they relate to one another.

## Publication Types


| Type | Scope | Publications | Namespace | Described at |
|---|---|---|---|---|
| Reference Architectures | Describes relationships among the entities of some environment | PAERA, the GovStack Architecture, Domain Reference Architectures | govstack:ra | [Reference Architectures](/chapters/reference_architectures) chapter |
| Specifications | Describe requirements, design, behavior, or other expected characteristics of the entity | Building Block Specifications, Cross-Functional Requirements | govstack:spec | Specification Framework |
| Guides | Provide guidance on how to implement a GovStack offering in a specific context. | Implementation Playbook, Service Patterns, implementation guides | govstack:guide | [Guides](/chapters/guides) chapter |
| Terminologies | Define the terms shared across GovStack publications, and the rules for writing them | Crafting GovStack Terminologies, shared terminologies | govstack:terminology | [Terminologies](/chapters/terminologies) chapter |

Other publication types whose scope is under evaluation to be included:
- [Reference Use Cases](https://govstack.gitbook.io/use-cases): Provide examples in which define a set of high-level steps to accomplish a specific task. GovStack already has several of them. 
- [Service Patterns](https://specs.govstack.global/service-patterns): Now considered a Guide but describing how they fit within our offerings and the process for publishing them is under evaluation.

In general, GovStack Specifications are normative artifacts that can be complied against, while Reference Architectures and Guides are the informative documents.

## Related chapters

The chapters that follow this one describe each publication type. The chapters under *Publication
process* describe how a publication of any type is owned, proposed, identified, compiled and
recorded:

- `govstack_working_groups.md` describes the Working Groups that own publications.
- `publication_tracks.md` sets out the lifecycle each publication moves through.
- `govstack_namespaces.md` sets the rules for identifiers.
- `compiling_publications.md` sets out what a repository needs for compilation and release.
- `govstack_registry.md` records the identifiers issued and the versions released.
